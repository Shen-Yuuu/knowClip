# 知微 KnowClip - 项目总览

## 项目定位

知微是一款"碎片化知识时代的本地 Zotero"，帮助用户将短视频、短文章中的截图、文本、链接沉淀为可搜索、可编辑、可回顾的本地知识库。

**核心原则：**
- 默认纯端侧处理，不调用云端内容分析 API
- 用户内容未经主动操作不得上传
- 本地优先，隐私优先

## 技术栈

- **平台**: HarmonyOS NEXT (API 12+)
- **语言**: ArkTS
- **UI框架**: ArkUI
- **应用模型**: Stage 模型
- **数据库**: 关系型数据库 (RDB)
- **OCR**: CoreVisionKit
- **分享接收**: ShareExtensionAbility + Share Kit + UDMF

## MVP 核心功能

### 已确认入口
1. **系统分享** - 从其他应用分享图片/文本/链接到知微
2. **系统相册 Picker** - 手动从相册选择图片导入
3. **App 内手动创建** - 粘贴文本或链接，添加图片

### 核心能力
1. **内容接收与存储** - 将分享内容复制到私有目录
2. **端侧 OCR** - 使用 CoreVisionKit 识别图片文字
3. **中文搜索** - 在 OCR 文本、关键词、笔记中搜索
4. **知识管理** - 文件夹分类、标星、归档
5. **本地备份** - 导出和恢复数据库+附件

## 不纳入 MVP 的能力

以下为实验性或未验证能力，**不作为本阶段实现前提**：

❌ 控制中心快捷入口
❌ 智慧识屏服务提供方
❌ 跨应用自动截图
❌ Window API 截取其他应用页面
❌ 跨设备同步
❌ 图像语义识别
❌ 记忆卡片
❌ 悬浮窗

## 开发阶段

### 第 0 阶段：技术验证（当前）
- 原型 A：系统分享接收
- 原型 B：端侧 OCR 处理
- 原型 C：中文搜索验证
- 低保真页面设计

### 第 1 阶段：最小纵向闭环
分享一张截图 → 私有目录复制 → pending 条目 → OCR → 关键词 → 入库 → 首页展示 → 搜索找到 → 详情编辑

### 第 2 阶段：完整 MVP
实现所有核心功能和页面

## Go/No-Go 条件

只有以下三项均通过真机验证，才允许进入正式开发：
1. ✅ 系统分享接收（图片、文本、链接）
2. ✅ 端侧 OCR（中文识别、错误处理）
3. ✅ 中文搜索（FTS 或 LIKE 方案）
