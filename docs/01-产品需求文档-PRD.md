# 知微 KnowClip - 产品需求文档 (PRD)

## 一、产品愿景

在碎片化知识时代，用户每天在短视频、社交媒体、即时通讯中接触大量有价值的信息片段（截图、文字、链接），但这些内容分散在各个应用的聊天记录、相册、收藏夹中，难以检索和沉淀。

**知微定位为"碎片化知识的本地 Zotero"**，提供一个私密、可搜索、可编辑的本地知识库，帮助用户将碎片信息转化为长期知识资产。

## 二、用户场景

### 核心场景
1. **刷短视频看到金句** - 截图后分享到知微，自动 OCR 识别文字
2. **微信群里的资料图** - 长按分享到知微，添加笔记和标签
3. **小红书/抖音的教程截图** - 多图分享，OCR 后统一管理
4. **浏览器复制的文章链接** - 分享到知微，记录来源和摘要
5. **相册里的往期截图** - 批量导入，OCR 后变得可搜索

### 典型用户
- **知识工作者** - 需要整理大量碎片信息
- **学习者** - 收集课程笔记、教程截图
- **内容创作者** - 积累素材和灵感
- **隐私敏感用户** - 不希望上传到云端

## 三、功能需求

### 3.1 内容接收 (MVP)

#### 系统分享入口
- 从任意应用的分享菜单选择"知微"
- 支持内容类型：
  - 单张图片
  - 多张图片（批量）
  - 纯文本
  - 链接（URL）
  - 混合内容（图片+文本+链接）

#### 系统相册 Picker
- App 内手动触发相册选择器
- 支持多选
- 检测并提示重复内容

#### App 内手动创建
- 粘贴文本或链接
- 添加一张或多张图片（相机拍摄或相册选择）
- 添加笔记和文件夹分类

### 3.2 内容处理 (MVP)

#### 图片处理
1. **URI 及时复制** - 将图片从系统 URI 复制到私有目录
2. **缩略图生成** - 用于列表展示
3. **EXIF 信息提取** - 拍摄时间、地理位置（可选）

#### OCR 识别
1. **端侧识别** - 使用 CoreVisionKit，不上传云端
2. **自动触发** - 图片保存后自动识别
3. **处理状态** - pending、processing、completed、failed
4. **错误重试** - 失败后允许手动重试
5. **性能优化** - 图片降采样、方向处理

#### 关键词提取
- 从 OCR 文本中提取中文关键词（简单分词）
- 用户可手动添加和编辑标签

### 3.3 知识管理 (MVP)

#### 首页时间流
- 按创建时间倒序展示
- 每条显示：缩略图/附件类型、文本摘要、关键词、处理状态
- 支持标星、删除
- 长按或滑动显示更多操作

#### 文件夹
- **系统文件夹**：收件箱、全部、标星、归档
- **自定义文件夹**：用户创建，支持嵌套
- 一个知识条目可属于多个文件夹（标签式）

#### 搜索
- **全文搜索**：OCR 文本、笔记、关键词
- **搜索历史**
- **筛选**：按文件夹、日期、有无图片、处理状态
- **特殊字符处理**：自动转义或提示

### 3.4 知识详情 (MVP)

#### 详情页展示
- 原始附件（图片、链接）
- OCR 识别文本（可编辑）
- 关键词（可编辑）
- 来源信息：分享来源应用、链接、分享文本
- 元数据：创建时间、修改时间、OCR 置信度
- 用户笔记（富文本编辑）

#### 操作
- 编辑笔记和关键词
- 移动到文件夹
- 标星/取消标星
- 归档
- 删除
- 重新识别（OCR 失败时）
- 分享（导出为图片+文本）

### 3.5 本地备份 (MVP)

#### 导出
- 导出内容：数据库 + 附件目录 + manifest.json
- 导出格式：ZIP 压缩包
- 导出位置：系统下载目录或用户选择

#### 恢复
- 校验备份包完整性
- 提示覆盖风险
- 恢复后验证数据一致性

### 3.6 设置 (MVP)

- **隐私说明**：本地处理，不上传用户内容
- **通知开关**：OCR 完成通知
- **存储管理**：查看占用空间，清理缓存
- **关于**：版本号、开源协议

## 四、非功能需求

### 4.1 性能
- OCR 单张图片识别耗时 < 5s（中等尺寸）
- 搜索响应时间 < 500ms（1000 条以内）
- 首页列表滚动流畅（60fps）

### 4.2 隐私与安全
- **本地优先**：所有内容处理在设备端完成
- **权限最小化**：仅申请必要权限
- **用户主动操作**：内容不自动上传或分享
- **数据加密**：备份文件可选加密

### 4.3 兼容性
- 支持 HarmonyOS NEXT API 12+
- 支持手机和平板
- 支持深色模式

### 4.4 类型安全
- 禁止使用 `any`、`as any`
- 禁止未经校验的 `JSON.parse` 结果
- 禁止非空断言（`!`）

## 五、MVP 范围界定

### 包含
✅ 系统分享接收（图片、文本、链接）
✅ 系统相册 Picker
✅ App 内手动创建
✅ 端侧 OCR（CoreVisionKit）
✅ 中文搜索（FTS 或 LIKE）
✅ 文件夹管理
✅ 知识详情编辑
✅ 本地备份与恢复

### 不包含（未来迭代）
❌ 跨设备同步
❌ 控制中心快捷入口
❌ 智慧识屏
❌ 跨应用自动截图
❌ 图像语义识别
❌ 记忆卡片
❌ 悬浮窗
❌ 云端备份
❌ 多人协作

## 六、成功指标（未来）

- 用户留存率（7 日、30 日）
- 日均添加条目数
- 搜索使用频率
- OCR 成功率
- 用户评分
