## 二、页面详细设计

### 1. 首页（时间流）

#### 布局结构

```
┌─────────────────────────────────┐
│  ┌─┐  知微          🔍  📁      │  ← 顶部导航栏
├─────────────────────────────────┤
│                                 │
│  ┌───────────────────────────┐ │
│  │ [图] 如何在鸿蒙系统中...  │ │  ← 知识卡片 1
│  │ 🏷️ 鸿蒙 数据库 RDB       │ │
│  │ ⏱️ 2 小时前  ⭐           │ │
│  └───────────────────────────┘ │
│                                 │
│  ┌───────────────────────────┐ │
│  │ [文] HarmonyOS NEXT...   │ │  ← 知识卡片 2
│  │ 🏷️ 分布式 跨设备          │ │
│  │ ⏱️ 昨天  🔄 处理中         │ │
│  └───────────────────────────┘ │
│                                 │
│  ┌───────────────────────────┐ │
│  │ [链] claude.ai 官网      │ │  ← 知识卡片 3
│  │ 🔗 https://claude.ai     │ │
│  │ ⏱️ 3 天前                 │ │
│  └───────────────────────────┘ │
│                                 │
│                           [+]   │  ← 添加悬浮按钮
└─────────────────────────────────┘
```

#### 组件清单

**顶部导航栏**
- Logo/标题：左对齐，"知微"
- 搜索按钮：右侧第二位，点击进入搜索页
- 文件夹按钮：右侧第一位，点击进入文件夹页
- 背景色：深色主题 `#0F131C`

**知识卡片（KnowledgeCard）**
- 附件类型图标：
  - `[图]` 图片（缩略图）
  - `[文]` 纯文本
  - `[链]` 链接
  - `[多]` 多张图片
- 文本摘要：最多显示 2 行，超出省略号
- 关键词标签：最多显示 3 个，横向排列
- 元信息行：
  - 时间：相对时间（2 小时前、昨天、3 天前）
  - 标星图标：已标星显示实心 ⭐，未标星显示空心 ☆
  - 处理状态：
    - `pending`：⏳ 待处理
    - `processing`：🔄 处理中
    - `completed`：无图标
    - `failed`：⚠️ 失败
- 长按操作：弹出菜单（编辑、标星、移动、删除）

**悬浮添加按钮**
- 位置：右下角固定
- 点击：弹出选项
  - 从相册导入
  - 手动创建
  - 拍照

**空状态**
```
┌─────────────────────────────────┐
│                                 │
│          📋                     │
│      还没有知识条目              │
│                                 │
│  点击右下角 [+] 开始添加         │
│  或从其他应用分享内容到知微       │
│                                 │
└─────────────────────────────────┘
```

#### 状态设计

**加载中**
- 显示骨架屏（3-5 个占位卡片）
- 每个卡片显示灰色占位块

**加载失败**
- 显示错误提示："加载失败，点击重试"
- 提供重试按钮

**下拉刷新**
- 支持下拉刷新
- 显示刷新动画

**上拉加载更多**
- 滚动到底部自动加载下一页
- 显示"加载中..."或"已全部加载"

#### 布局结构

```
┌─────────────────────────────────┐
│  ← 分享到知微              ✕    │  ← 标题栏
├─────────────────────────────────┤
│                                 │

│                                 │
│  ┌───────────────────────────┐ │
│  │                           │ │
│  │      [图片预览]            │ │  ← 附件预览区
│  │                           │ │
│  └───────────────────────────┘ │
│                                 │
│  ┌───────────────────────────┐ │
│  │ 这是分享的文本内容...      │ │  ← 文本预览
│  └───────────────────────────┘ │
│                                 │
│  🔗 https://example.com         │  ← 链接（如有）
│                                 │
│  📁 收件箱                      │  ← 目标文件夹
│                                 │
│  ⏳ 准备接收...                 │  ← 状态提示

├─────────────────────────────────┤
```

#### 状态设计

**准备接收**
- 提示："⏳ 准备接收..."
- 按钮："保存"（可点击）

**复制中**
- 提示："🔄 正在复制文件..."
- 进度条
- 按钮："保存"（禁用）

**复制成功**
- 提示："✅ 已保存到收件箱"
- 按钮："完成"

**复制失败**
- 提示："⚠️ 保存失败：存储空间不足"
- 按钮："重试" + "取消"

**OCR 处理中**（后台）
- 提示："已保存，正在识别文字..."
- 自动关闭页面

### 3. 手动创建页

#### 布局结构

```
┌─────────────────────────────────┐
│  ← 创建知识              ✓      │  ← 标题栏 + 保存按钮
├─────────────────────────────────┤
│                                 │
│  ┌─────────────────────────┐   │
│  │ 粘贴文本或链接...       │   │  ← 文本输入框
│  │                         │   │
│  │                         │   │
│  └─────────────────────────┘   │
│                                 │
│  ┌───┐ ┌───┐ ┌───┐            │  ← 图片缩略图
│  │ 1 │ │ 2 │ │ + │            │
│  └───┘ └───┘ └───┘            │
│                                 │
│  📁 收件箱  ▼                   │  ← 文件夹选择器
│                                 │
│  🏷️ 添加标签...                │  ← 标签输入
│                                 │
└─────────────────────────────────┘
```

#### 交互说明

**文本输入框**
- 支持多行输入
- 自动检测链接并显示预览
- 字数限制：10000 字

**图片添加**
- 点击 `[+]` 按钮：弹出选项
  - 拍照
  - 从相册选择
- 已添加图片：显示缩略图，长按删除
- 最多支持 9 张图片

**文件夹选择器**
- 点击：弹出文件夹列表
- 默认选择"收件箱"

**标签输入**
- 输入标签，按回车添加
- 显示标签气泡，点击删除

**保存按钮**
- 至少有文本或图片才可保存
- 点击：创建知识条目，返回首页

#### 布局结构

```
┌─────────────────────────────────┐
│  ← 详情        ⭐ ⋯             │  ← 标题栏 + 操作
├─────────────────────────────────┤

│  │                         │   │

│                                 │
│  📝 识别文本                    │
│  ┌─────────────────────────┐   │
│  │ 如何在鸿蒙系统中实现...  │   │  ← OCR 文本（可编辑）
│  │                         │   │
│  └─────────────────────────┘   │
│  ✅ 置信度：92%                 │
│                                 │

│                                 │

│  • 来源：微信                   │
│  • 分享时间：2024-01-15 13:45  │
```

#### 组件清单

**顶部操作栏**
- 返回按钮：左侧
- 标星按钮：右侧第二位
- 更多菜单：右侧第一位
  - 编辑
  - 移动到文件夹
  - 重新识别（OCR 失败时）
  - 分享
  - 删除

**附件区域**
- 图片：显示原图，可缩放、滑动查看多图
- 链接：显示链接卡片，点击打开浏览器
- 视频/音频：显示播放器（未来迭代）

**OCR 文本区域**
- 默认只读，点击"编辑"按钮进入编辑模式
- 显示置信度（如果可获取）
- OCR 失败时显示：
  ```
  ⚠️ 文字识别失败
  原因：图片格式不支持
  [重新识别]
  ```

**关键词区域**
- 标签气泡展示
- 点击 `[+]`：添加新关键词
- 点击标签：跳转到该关键词的搜索结果

**来源信息**
- 来源应用（如果可获取）
- 分享时间
- 原始分享文本
- 链接（如果有）

**文件夹**
- 显示当前所属文件夹
- 点击：移动到其他文件夹

**笔记编辑**
- 支持多行输入
- 支持富文本（加粗、列表等，未来迭代）
- 自动保存

#### 状态设计

**OCR 处理中**
```
📝 识别文本
┌─────────────────────────┐
│ 🔄 正在识别文字...       │
└─────────────────────────┘
```

**OCR 失败**
```
📝 识别文本
┌─────────────────────────┐
│ ⚠️ 文字识别失败          │
│ 原因：内存不足            │
│ [重新识别]               │
└─────────────────────────┘
```

**编辑模式**
- OCR 文本框变为可编辑
- 底部显示工具栏："取消" + "保存"

```
│                                 │
```

#### 交互说明

**搜索框**
- 实时搜索（输入后 300ms 触发）
- 显示清除按钮（输入后）
- 显示搜索按钮

**搜索历史**
- 显示最近 10 条
- 点击：自动填入搜索框
- 长按：删除该条历史
- 清空按钮：清空所有历史

**筛选器**
- 全部/有图/无图
- 今天/本周/本月/全部时间
- 文件夹筛选
- 处理状态筛选

**结果列表**
- 与首页卡片样式一致
- 关键词高亮（未来迭代）
- 点击：进入详情页

**无输入**
- 显示搜索历史


- 显示结果数量："找到 12 条结果"
- 显示结果列表

```
│  尝试使用其他关键词              │
│  或调整筛选条件                  │
│                                 │
└─────────────────────────────────┘
```

**特殊字符错误**
```
⚠️ 搜索词包含特殊字符，请使用其他关键词
```

**搜索失败**
```
⚠️ 搜索失败，请重试
[重试]
```

## 四、异常状态汇总

### 全局异常

| 异常 | 触发条件 | 显示内容 | 操作 |
|------|---------|---------|------|
| 权限拒绝 | 用户拒绝相册权限 | "无法访问相册，请在设置中授权" | 跳转系统设置 |
| 存储空间不足 | 可用空间 < 50MB | "存储空间不足，请清理后重试" | 跳转存储管理 |
| 网络错误 | 无网络（仅同步时） | "网络连接失败" | 重试按钮 |
| 数据库错误 | 数据库损坏 | "数据加载失败，请重启应用" | 重启按钮 |

### 页面异常

**首页**
- 空状态：无知识条目
- 加载失败：数据库读取错误

**搜索页**
- 无结果：搜索词不匹配
- 特殊字符错误：包含不支持字符
- 搜索失败：数据库查询错误

**详情页**
- 附件加载失败：文件已删除或损坏
- OCR 处理中：显示处理动画
- OCR 失败：显示错误原因和重试按钮

**分享接收**
- URI 失效：文件已被删除
- 复制失败：存储空间不足或权限问题
- 用户取消：正常退出

**相册导入**
- 权限拒绝：跳转设置授权
- 导入失败：存储空间不足
- 部分失败：显示成功和失败数量

**备份恢复**
- 导出失败：存储空间不足
- 恢复失败：备份文件损坏或版本不兼容
- 校验失败：文件格式错误

## 五、视觉设计原则（低保真阶段）

### 颜色语义

- **成功**：绿色 `#6EE7B7` / ✅
- **失败/错误**：红色 `#F87171` / ⚠️ / ❌
- **处理中**：蓝色 `#38BDF8` / 🔄
- **待处理**：黄色 `#FCD34D` / ⏳
- **信息**：灰色 `#9CA3AF` / ℹ️

### 图标使用

- **标星**：⭐（已标星）/ ☆（未标星）
- **文件夹**：📁 / 📂
- **收件箱**：📥
- **归档**：📦
- **搜索**：🔍
- **添加**：[+]
- **关键词**：🏷️
- **笔记**：✏️
- **图片**：🖼️
- **链接**：🔗
- **时间**：⏱️

### 间距规范

- 页面边距：20px
- 卡片间距：10px
- 组件内边距：10-15px
- 文本行高：1.5

### 字体大小

- 标题：24px，粗体
- 二级标题：18px，粗体
- 正文：14-16px
- 辅助文字：12px，灰色
