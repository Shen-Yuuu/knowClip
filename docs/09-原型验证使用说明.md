### 准备工作

1. **连接真机**

2. **构建项目**

   ```bash

   Run > Run 'entry'
   ```

### 原型 A：系统分享接收测试

**测试目标**：验证从其他应用分享内容到知微

**测试步骤**：

1. **启动知微应用**
   - 点击应用图标
   - 进入首页，确认应用正常启动

2. **测试场景 1：分享单张图片**
   - 打开系统相册
   - 选择一张图片
   - 点击分享按钮
   - 在分享面板中选择"知微"
   - **记录**：
     - [ ] 分享面板是否显示"知微"
     - [ ] 是否跳转到分享确认页
     - [ ] 图片 URI 是否正确显示
     - [ ] 来源应用信息（如果可获取）
   - 点击"保存"
   - **记录**：
     - [ ] 文件是否成功复制到私有目录
     - [ ] 复制耗时：___ ms
     - [ ] 数据库是否创建条目

3. **测试场景 2：分享多张图片**
   - 打开系统相册
   - 选择 5 张图片
   - 点击分享按钮，选择"知微"
   - **记录**：
     - [ ] 是否显示所有图片
     - [ ] 批量复制耗时：___ ms
     - [ ] 是否全部成功

4. **测试场景 3：分享纯文本**
   - 打开笔记应用或浏览器
   - 选择一段文本，点击分享
   - 选择"知微"
   - **记录**：
     - [ ] 文本是否正确显示
     - [ ] 是否正确保存

5. **测试场景 4：分享链接**
   - 打开浏览器
   - 点击分享链接，选择"知微"
   - **记录**：
     - [ ] 链接是否正确提取
     - [ ] URL 格式是否正确

6. **测试场景 5：用户取消**
   - 开始分享流程
   - 在分享确认页点击"取消"
   - **记录**：
     - [ ] 是否正常退出
     - [ ] 是否有崩溃或错误

7. **查看测试结果**
   - 返回知微应用
   - 点击"原型 A：分享接收测试"
   - 点击"查看数据库统计"
   - **记录测试结果**：
     ```
     总条目数: ___
     待处理: ___
     已完成: ___
     失败: ___
     ```

**预期结果**：
- ✅ 至少 8/10 测试场景通过
- ✅ URI 复制成功率 > 90%
- ✅ 复制耗时 < 1000ms

### 原型 B：OCR 识别测试

**测试目标**：验证端侧 OCR 识别能力和性能

**测试步骤**：

1. **准备测试图片**
   - 从真实场景收集 20 张包含文字的图片：
     - 微信聊天截图：5 张
     - 小红书/抖音内容截图：5 张
     - 文章/新闻截图：5 张
     - 低分辨率图片：3 张
     - 手写文字（预期失败）：2 张

2. **启动 OCR 测试**
   - 在知微首页点击"原型 B：OCR 测试"
   - 点击"选择多张图片（批量测试）"
   - 从相册选择准备好的 20 张图片
   - 点击"开始识别"

3. **记录测试过程**
   - 观察识别进度
   - 等待所有图片识别完成
   - 点击"查看统计信息"

4. **记录测试结果**
   ```
   === OCR 测试结果 ===
   测试图片总数: 20
   识别成功: ___ 张
   空结果: ___ 张
   识别失败: ___ 张
   
   平均耗时: ___ ms
   最快: ___ ms
   最慢: ___ ms
   
   可重试错误: ___ 次
   不可重试错误: ___ 次
   
   识别质量评估:
   - 完全正确: ___ 张
   - 部分正确: ___ 张
   - 完全错误: ___ 张
   ```

5. **识别质量检查**
   - 滚动查看每条结果
   - 对比识别文本和原图
   - 记录常见错误：
     - [ ] 相似字符混淆（0/O、l/I）
     - [ ] 标点符号丢失
     - [ ] 换行处理不当
     - [ ] 特殊符号识别错误

**预期结果**：
- ✅ 识别成功率 > 70%
- ✅ 平均耗时 < 5s
- ✅ 错误可正确分类（可重试 vs 不可重试）

## 常见问题

### Q1: 分享面板没有显示"知微"
**可能原因**：
- ShareExtensionAbility 配置错误
- module.json5 中 skills 配置不正确
- 应用未正确安装

**解决方案**：
1. 检查 module.json5 配置
2. 卸载应用后重新安装
3. 检查系统日志

### Q2: OCR 全部识别失败
**可能原因**：
- CoreVisionKit 在当前设备不可用
- 图片路径错误
- 权限问题

**解决方案**：
1. 检查系统日志中的错误码
2. 确认图片 URI 有效
3. 检查权限配置

### Q3: 搜索耗时过长
**可能原因**：
- 数据量过大
- 索引缺失
- LIKE 查询未优化

**解决方案**：
1. 确认索引已创建
2. 检查 SQL 查询语句
3. 考虑降级到更简单的实现
