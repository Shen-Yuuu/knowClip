## 📊 Go/No-Go 决策标准

### 必须全部通过

| 原型 | 通过标准 | 预期通过概率 |
|------|---------|------------|
| 原型 A | ≥ 8/10 场景通过，URI 复制成功率 > 90% | 85% |
| 原型 B | ≥ 15/20 成功，平均耗时 < 5s | 75% |
| 原型 C | 搜索耗时 < 500ms，召回率 > 80% | 95% |

### 可接受的不完美

- ⚠️ OCR 识别率 70-90%（允许用户编辑）
- ⚠️ 搜索方案使用 LIKE（FTS4 不可用）
- ⚠️ 无法获取分享来源应用名称（非核心）

### 不可接受的失败

- ❌ 系统分享完全无法接收
- ❌ OCR 全部失败或崩溃
- ❌ 中文搜索完全不可用或超时严重

Tools -> Device Manager

Build -> Build Hap(s)/APP(s) -> Build Hap(s)

## ⚠️ 已知限制

1. **ShareExtensionAbility 限制**：
   - 只能接收系统标准分享类型
   - 无法截取其他应用的窗口内容
   - URI 有效期取决于来源应用

2. **OCR 限制**：
   - 依赖 CoreVisionKit 系统实现
   - 识别率可能不如云端 API
   - 不支持手写识别

3. **搜索限制**：
   - 当前使用 LIKE 方案（兜底）
   - FTS4 可用性未验证
   - 大数据量性能待验证（仅测试 100 条）

4. **UI 限制**：
   - 仅实现测试页面，无完整 UI
   - 深色主题硬编码
   - 无动画和过渡效果
