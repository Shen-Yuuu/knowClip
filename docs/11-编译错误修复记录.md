## 修复清单

### 1. ShareExtensionAbility 导入错误 ✅

**错误**：
```
Module '@kit.ShareKit' has no exported member 'ShareExtensionAbility'
Module '@kit.ShareKit' has no exported member 'UIExtensionContentSession'
```

**原因**：HarmonyOS NEXT API 12 的 @kit.ShareKit 中没有导出 ShareExtensionAbility

**修复方案**：
```typescript
// 修改前
import { ShareExtensionAbility, UIExtensionContentSession } from '@kit.ShareKit';

// 修改后
import { UIExtensionAbility, UIExtensionContentSession } from '@kit.AbilityKit';
```

同时修改类继承：
```typescript
// 修改前
export default class ShareExtAbility extends ShareExtensionAbility

// 修改后
export default class ShareExtAbility extends UIExtensionAbility
```

并更新 `module.json5` 配置：
```json5
{
  "type": "sys/commonUI"  // 从 "share" 改为 "sys/commonUI"
}
```

## 类型安全原则总结

1. **禁止 any/unknown**：所有变量和参数必须有明确类型
2. **显式接口声明**：对象字面量必须对应已声明的接口或类
3. **类型守卫**：使用 `instanceof` 和 `as` 进行类型断言，避免 `in` 操作符
4. **可选链**：访问可能为 undefined 的属性使用 `?.` 和 `??`
5. **严格导入**：所有使用的 API 必须正确导入
6. **错误类型**：throw 语句必须抛出明确类型的错误对象
